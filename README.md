# Problem Statement

**InsighBI** is an interactive Power BI dashboard designed to analyze the sales performance of men's T-shirt brands using data stored in **Microsoft Azure**. The dashboard provides valuable business insights into discounts, profitability, sales prices, and product variety across multiple brands.

The dashboard helps business stakeholders answer key questions such as:

- Which brands offer the highest average discounts?
- Which brands generate the highest average profit?
- Which brands have the highest average selling price?
- Which brands provide the largest variety of products?
- Which brands have the lowest profitability?

These insights help businesses optimize pricing strategies, improve profitability, and make data-driven decisions.

---

# Data Source

- **Cloud Platform:** Microsoft Azure
- **Visualization Tool:** Microsoft Power BI Desktop
- **Dataset:** Men's T-Shirt Dataset
- **Data Cleaning:** Power Query
- **Data Modeling:** DAX

---

# Steps Followed

- **Step 1:** Connected Microsoft Azure as the data source in Power BI Desktop.
- **Step 2:** Imported the Men's T-Shirt dataset.
- **Step 3:** Cleaned and transformed the data using Power Query Editor.
- **Step 4:** Removed duplicate records and handled missing values.
- **Step 5:** Assigned appropriate data types to all columns.
- **Step 6:** Created calculated measures using DAX.
- **Step 7:** Designed a custom dashboard theme.
- **Step 8:** Built interactive visualizations for brand comparison.
- **Step 9:** Added report page navigation.
- **Step 10:** Published the report to Power BI Service.

## 1. Top 5 Brands by Average Discount

# Business Conclusions

- The Indian Garage Co leads in both discount offerings and product variety.
- Premium brands such as ARMANI EXCHANGE command significantly higher selling prices.
